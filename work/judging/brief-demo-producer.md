## The product
Countersign: "AI reviews. A named human countersigns." It turns a real GitHub pull request written by an AI agent into a guided review: acceptance criteria derived from the requirement only (by an agent that never saw the code); the change split into units; a sandbox that runs red→green tests, regression suites, ablation (revert each hunk, see if a test notices) and independent probe tests; findings that a second agent tried to refute before they reach you (killed findings stay visible); a reviewer self-test with planted bugs; decisions the AI refuses to make and hands to the owner; a reading budget ("read 39 of 228 lines; the rest is covered by proof you can re-run"); a named human sign-off that is a hash-chained attestation and the GitHub merge check; a trust ledger that measures the reviewer per code area (escapes, false alarms, time to merge, share routed to humans). Diagrams and "Ask" answers are generated live with Gemini and are labelled as explanation, never evidence.
